Regulatory map

See how a principal law links to the instruments that sit within it, and how each state and territory adopts, varies and adds to a national code. The National Construction Code is the first map.

An early version. The map shows the structure the code itself describes, as read from its published data by AI-assisted desk research. It is a draft until a person has checked it. Choose a node to see what it is and how it links; choose a state or territory to see only its part.

How the parts fit together

Each dot is a law, part of the code, a state’s adoption or variations, or a standard the code calls up. Lines run from a part to the parts within it. Colour shows the jurisdiction; shape shows the kind of part.

About this map

Choose a dot to see its details, and double-click it (or use “Show its links”) to open the parts linked to it. Drag a dot to move it; drag the background to move the map; scroll or use the buttons to zoom. Choosing a state or territory hides the others’ adoptions, variations and laws, and opens that jurisdiction’s adoptions and variations. Standards and other laws start hidden because there are many of them.

The map does not show councils’ rules, or rules a state sets outside the code (such as Queensland’s own development code or New South Wales’s BASIX), except where a state’s appendix to the code names them. A law that could not be matched to a state register has no register id yet.

How much each state and territory varies the code

Provisions varied, by volume. Darker cells vary more provisions. Choose a jurisdiction to see its part of the map.

A provision is varied when a state or territory inserts, replaces or deletes it in its appendix to the code. Laws giving effect: the state laws that adopt the code. Other laws listed: the other legislation the state’s appendix says a builder must also meet.

About these figures

Each count is the number of provisions a jurisdiction’s variations insert, replace or delete in that volume, summed over the code’s areas. A count says how much of the code a state changes, not how much each change costs. A jurisdiction with no variations in the data shows 0. Variation counts are for the latest edition in the data.
